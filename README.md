# Raktdaan Connect 🩸

A beginner-friendly, responsive front-end prototype for a blood donation request and availability coordination platform.

## Run it

1. Download or clone this repository.
2. Open the `raktdaan-connect` folder.
3. Double-click `index.html` to open it in a browser.

For a smoother development experience, open the folder in VS Code and use the **Live Server** extension.

## Features in this prototype

- Responsive landing page
- Blood request form
- Donor-interest registration form
- Request board with blood-group and city filters
- Browser `localStorage` persistence
- Mobile navigation
- Sample request cards clearly marked as fictional
- Safety and verification notices

## Important limitations

This is a **front-end demo only**. It does not have a backend, user accounts, real-time blood-bank inventory, identity verification, location services, SMS/email notifications, or live donor matching. Data is saved only in the browser where the app is opened; it is not shared with teammates or other users.

Do not enter real patient or donor personal information into this demo. The sample requests are fictional and their contact numbers are placeholders. This prototype must not be used to make medical decisions or to confirm blood availability or donor eligibility.

For an urgent medical need, contact the treating hospital, a licensed blood bank, or local emergency services immediately. Blood donation and eligibility screening should be handled by qualified professionals at licensed facilities.
